# Contributing

Thank you for your interest in the Delinea Workload Secrets Vault SDK for Go.

## How this repository works

This repository is where the SDK is published. Development and review happen
in Delinea's internal repository, and each release is copied here. Because of
that, pull requests opened here cannot be merged. If you have a change in mind,
open an issue describing it instead, and we will consider it for a future
release.

## Reporting a bug or asking for a feature

Open an issue and include:

- the SDK version (from your `go.mod`) and your Go version (`go version`);
- what you did, what you expected and what happened;
- the error text, and a short program that shows the problem, if you can.

Never include a real secret, client secret or access token in an issue.

For help with your Workload Secrets Vault tenant or account, contact your Delinea
private preview contact.

## Reporting a vulnerability

Do not open a public issue. See [SECURITY.md](SECURITY.md).
